# Telegram Bot como interface conversacional primária e canal de proatividade

## Contexto & Decisão

Para minimizar o esforço de desenvolvimento de UI no MVP e fornecer notificações push nativas para os check-ins proativos do Coach de IA, decidimos adotar o Telegram Bot (via Webhooks) como interface oficial do Paciente-Fundador.

## Consequências

- Custo zero de desenvolvimento de componentes visuais web/mobile no MVP.
- Suporte nativo a envio de mensagens ativas (bot inicia a conversa), fotos de refeição e mensagens de áudio.
